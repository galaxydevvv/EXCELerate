### Requirements:
- As of now, EXCELerate only works on macOS 
- Active Office 365 subscription or some way to access macro-assisted Excel files (xlsm)
- 64 KB of storage

### Controls:
- W | ↑ - EXCELerate!!!
- A/D | ←/→ - Steering
- S | ↓ - Slow down
- Esc - Emergency Stop
- All other button controls in sidebar.
